# SIMBO

Sistema Integral de Modelado y Despiece para BOIS Cocinas y Closets.

## Stack base

- Electron + Vite
- React + TypeScript
- SQLite + Prisma
- Zustand + TanStack Query
- Zod
- Three.js / React Three Fiber
- ExcelJS
- Vitest

## Scripts

```bash
npm install
npm run dev
npm run test
npm run build
npm run db:generate
npm run db:migrate
npm run db:seed
```
